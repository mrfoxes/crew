Three promises, and what keeps each

You already run two or three coding agents in terminal tabs by hand. crew keeps everything you have: the same agents, the same panes, the same local git, the same subscriptions, and adds only what hands cannot keep up with across panes.

1. See everything

Nothing runs in the background or inside a wrapper window. Every member is an ordinary agent session in an iTerm2 or tmux pane tinted in its kind's color, where you can watch the screen redraw, focus it, read its last lines, or type straight into it.

Kept by: crew panes, crew peek, crew poke, crew key, crew focus, crew layout, crew move

2. Read everything

Members talk through one numbered stream of plain Markdown files in .crew/messages/. A wake line types only the message number and sender into the recipient's pane; you read the stream, the plan, the statuses, and the end-of-session reports as plain text.

Kept by: .crew/messages/NNNN-*.md, .crew/README.md, crew send, crew unread, crew board, crew report, crew archive

3. Hold everything

crew gate approves every command prompt it reads that matches no rule in share/forbid or .crew/forbid, whatever the command, and holds the rest. crew status warns when two members claim the same path on Files:; crew land checks, takes the push lock, commits only that member's claimed paths, pushes, and wakes the reviewer.

Kept by: crew gate, forbid, crew lock, Files: claims, crew land, budget=

Sixty seconds from install to crew down

One line installs crew; then: 

curl -fsSL https://github.com/mrfoxes/crew/releases/latest/download/install.sh | sh

From a git repository, check your terminal and installed agents with crew doctor, bring up a crew with crew up, and watch the members work: 

# checks terminal, agents, skills, gh, Crewfile, rates
crew doctor
# opens watch, live board, and two members with a reviewer for each
crew up pair
# write the goal, lanes, reviewers, and end time
$EDITOR "$(crew dir)/README.md"
crew send coord all "Plan: start from README.md" <<'EOF'
Read $(crew dir)/README.md, claim your files with crew status, and land with crew land.
EOF
# full statuses, file claims, lock, messages, git, CI, cost
crew board
# sends End:, waits for Done:, archives stream, closes exited panes
crew down --archive --close

Each member joins with crew join <name>, which prints share/protocol.md, the session plan in .crew/README.md, and any unread messages. An agent needs no repo-specific instruction file to learn the protocol.

What crew is not

crew is not a cloud, not a framework, not a chat window, and not a dependency. It runs the terminal agents you already pay for, on your machine, in your terminal, over your local git checkout.

Category What it gives you What is missing What crew keeps and adds
Tabs or tmux by hand Real terminal panes, local git, your own agents and keys. No shared stream, no gate, no file claims, no push lock, no reviewer for each member. Keeps your panes and local git; adds the numbered stream, live board, gate, claims, lock, and crew land.
Cloud or background agents Parallel branches running on remote machines. Hidden screens, nothing you can type into mid-turn, separate from your local tools and checkout. Keeps every member visible in a local pane you can watch, focus, and type into at any moment.
In-process frameworks One program holding multiple transcripts. No terminals, no agent's own screen, transcripts kept in one process's context, extra dependencies. Runs each agent's own command in its own terminal pane and writes every message and status as plain Markdown in .crew/.
Worktree spawners Separate working trees so builds do not collide. No message stream between members, no gate holding dangerous commands, no reviewer for each member. Supports per-member clones (--clone and cache=) while keeping one stream, one board, one gate, and a reviewer for each member.

What it costs

crew is released under the MIT License. crew cost reads the agents' own logs on this machine (~/.codex/sessions/, ~/.claude/projects/, ~/.gemini/antigravity-cli/conversations/) and sends nothing; what crew sends over the network is git, for your clones and landings, and gh, for CI on the board. It prints tokens in five columns, plus dollars where the rates price the model: 

codex    input 36031  cached 118315581  write 1647717  output 261595  reasoning 181012  $72.62
agy      input 2730598  cached 28680398  write 0  output 300718  reasoning 159598  no rate for gemini-4-argon
total    input 2766629  cached 146995979  write 1647717  output 562313  reasoning 340610  $72.62

Write prices in .crew/rates or ~/.config/crew/rates, in dollars per million tokens. Set budget=<dollars> on a member's line in the Crewfile: crew board shows the percentage spent, crew doctor warns if a budgeted member has no matching rate, and crew watch notifies the owner at 80% and 100%, naming crew mute <name>. crew never stops or kills an agent by itself.

Commands

Tab completion for fish, zsh, and bash reads crew --help when Tab is pressed and completes commands, flags, members, keys, message numbers, and kinds.

For everyone

crew send <from> <to> <subject> Post a message, body on stdin; wakes <to> (a member, all, or owner).
crew unread <name> Print the messages to <name> or all not read yet and advance the cursor.

Gate rules (share/forbid and .crew/forbid)

crew gate tests every command prompt against extended regular expressions in .crew/forbid (or share/forbid when the crew has none). A line starting with ! is an exception, cut out of the command before the rules are tried. By default it holds destructive or shared-tree git commands (git reset, git checkout, git stash, git clean, git add -A, git commit -a, git commit --amend, git push --force), whole-tree formatters, kill, sudo, and recursive deletions (rm -rf), while allowing lock release (rm -rf .crew/lock), format checks (--check), and branch creation (git checkout -b, git switch -c).

Requirements

  • macOS with iTerm2 3.5+ (using osascript) or tmux 3.1+, or Linux with tmux 3.1+.
  • POSIX sh, awk, sed, and the tools macOS and Linux ship, plus git.
  • One or more terminal coding agents on PATH: Claude Code (claude), Codex (codex), Antigravity (agy), or your own kind in ~/.config/crew/kinds.
  • Optional: gh (for CI status on crew board), sqlite3 (for Antigravity token counts in crew cost), and notify-send on Linux (for desktop notifications to owner).
