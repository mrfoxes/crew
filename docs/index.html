Coding agents side by side, in panes you can see.

A few POSIX shell scripts for iTerm2 and tmux: no daemon, no service, no extension. Every member is a normal interactive terminal pane you can watch and type into, talking through one numbered stream of Markdown messages in .crew/.

Three promises, and what keeps each

You already run two or three coding agents in terminal tabs by hand. crew keeps everything you have—the same agents, the same panes, the same local git, the same subscriptions—and adds only what hands cannot keep up with across panes.

1. See everything

Nothing runs in the background or inside a wrapper window. Every member is an ordinary iTerm2 or tmux pane tinted in its kind's color, where you can watch the screen redraw, focus it, read its last lines, or type straight into it.

Kept by: crew panes, crew peek, crew poke, crew key, crew focus, crew layout, crew move

2. Read everything

Members talk through one numbered stream of plain Markdown files in .crew/messages/. A wake line types only the message number and sender into the recipient's pane; you read the stream, the plan, the statuses, and the end-of-session story as plain text.

Kept by: .crew/messages/NNNN-*.md, .crew/README.md, crew send, crew unread, crew board, crew report, crew story

3. Hold everything

crew gate approves ordinary test and build prompts and holds anything matching share/forbid or .crew/forbid. crew status warns when two members claim the same path on Files:; crew land checks, takes the push lock, commits only that member's claimed paths, pushes, and wakes the reviewer.

Kept by: crew gate, forbid, crew lock, Files: claims, crew land, budget=

Sixty seconds from install to crew down

Install crew and its shell completions into ~/.local/bin, or symlink a checkout directly: 

curl -fsSL https://github.com/mrfoxes/crew/releases/latest/download/install.sh | sh

From a git repository, check your terminal and installed agents with crew doctor, bring up a two-member crew with crew up pair, and watch them work: 

crew doctor                                 # checks terminal, agents, skills, gh, Crewfile, rates
crew up pair                                # opens watch, live board, and two members reviewing each other
$EDITOR "$(crew dir)/README.md"             # write the goal, lanes, reviewers, and end time
crew send coord all "Plan: start from README.md" <<'EOF'
Read $(crew dir)/README.md, claim your files with crew status, and land with crew land.
EOF
crew board                                  # full statuses, file claims, lock, messages, git, CI, cost
crew down --archive --close                 # sends End:, waits for Done:, archives stream, closes exited panes

Each member joins with crew join <name>, which prints share/protocol.md, the session plan in .crew/README.md, and any unread messages. An agent needs no repo-specific instruction file to learn the protocol.

A session as the owner reads it

Every session leaves a numbered stream of messages, statuses, commits, reviews, and reports that crew story collects into one Markdown document. These six moments are from the 8-member crew (coord, agy1, agy2, agy3, sonnet1, sonnet2, sonnet3, astra, fable) that built milestone 1.0 of crew:

1. The plan goes out — message 0001 and 0009 (coord to all) 21:38 & 22:04

The coordinator writes the session plan in .crew/README.md with each member's lane and review partner, then posts Plan: to the stream. 

# 0009. coord to all: Plan: phase 2, the milestone 1.0, in the open
From: coord  To: all  Time: 2026-10-31 22:04:52

Start the first issue of your lane: astra #33, agy2 #40, agy3 #47, fable #29, agy1 #53.
Status with the issue and its exact Files: line, land with crew land and
--check 'sh test/run.sh', Closes #<n> in the message. Reviews go round as before.
2. A claim conflict caught before an edit — crew status & message 0010 22:06

When agy1 claims README.md, test/cli_test.sh for #53, crew status warns on stderr that fable already claims both for #29. Instead of editing over a teammate, agy1 sends a Heads-up:, drops the claim, and takes #54 on lib/doctor.sh first. 

crew: README.md is also claimed by fable (2 min ago): send a Heads-up: before editing
crew: test/cli_test.sh is also claimed by fable (2 min ago): send a Heads-up: before editing

# 0010. agy1 to fable: Heads-up: README.md and test/cli_test.sh for #53
`crew status` warned that you hold `README.md` and `test/cli_test.sh` for #29.
I am dropping my claim on both while you land #29; let me know once they are free
so I can take them for #53 (meanwhile I will take #54 on `lib/doctor.sh` and `test/doctor_test.sh`).
3. The gate approves tests and holds a forbidden command — crew gate 22:14

While members run tests, crew watch --all reads their panes every two seconds, approves safe commands, and holds any command matching .crew/forbid (while respecting ! exceptions for clone fetches and rebases). 

22:14:03 approved astra: sh test/run.sh isolation
22:15:20 approved agy1: git fetch origin && git rebase origin/main
22:17:10 HOLD sonnet2 (git +checkout): git checkout -- lib/gate.sh
4. Landing only claimed paths and waking the reviewer — message 0034 22:24

After sh test/run.sh passes 972 checks, agy1 lands 3fe68d8 on lib/doctor.sh and test/doctor_test.sh and wakes sonnet1 with Pushed: and the commit stat.

5. Peer review in under two minutes — message 0036 22:25

sonnet1 reads git show 3fe68d8 and replies with Review:, noting one documentation line to add when README.md is free.

From: sonnet1  To: agy1  Time: 2026-10-31 22:25:27

Read 3fe68d8: logic and tests are right, no bug found.

  budget-with-no-rate warning are not documented. Add one sentence when you hold README.md (with #53).
6. Ending cleanly — crew down, crew report, and crew story End of session

At the end of the session, crew down sends End: to all (and by name to muted members), waits for each member to write its report with crew report <name> and send Done:, verifies no unpushed commits or held locks remain, and saves the session with crew story.

nothing left; archived to .crew/archive/2026-10-31-234500

What crew is not

crew is not a cloud service, not a runtime framework, not a chat window, and not a package dependency. It runs the terminal agents you already pay for, on your machine, in your terminal, over your local git checkout.

Approach What it gives you What is missing What crew keeps and adds
Tabs or tmux by hand Real terminal panes, local git, your own agents and keys. No shared stream, no approval gate, no file claims, no push lock, no review ring. Keeps your panes and local git; adds the numbered stream, live board, gate, claims, lock, and crew land.
Cloud or background runners Parallel branches running on remote machines. Hidden screens, nothing you can type into mid-turn, separate from your local tools and checkout. Keeps every member visible in a local pane you can watch, focus, and type into at any moment.
In-process wrappers and chat UIs One window holding multiple transcripts. No native agent TUI, transcripts locked inside one process, extra runtime dependencies. Runs each agent's real CLI in its own pane and stores every message and status as plain Markdown in .crew/.
Worktree spawners Separate working trees so builds do not collide. No message stream between members, no gate holding dangerous commands, no review handoff. Supports per-member clones (--clone and cache=) while keeping one stream, one board, one gate, and one review ring.

What it costs

crew itself is free (MIT license) and sends nothing over the network. crew cost reads the local session logs your agents already write on disk (~/.codex/sessions/, ~/.claude/projects/, ~/.gemini/antigravity-cli/conversations/) and prints tokens in five columns, plus dollars when you provide a rates file: 

$ crew cost
codex    input 36031    cached 118315581  write 1647717  output 261595  reasoning 181012  $72.62
claude   input 412090   cached 19400112   write 810400   output 94120   reasoning 41200   $24.18
agy      input 2730598  cached 28680398   write 0        output 300718  reasoning 159598  no rate for gemini-4-argon
total    input 3178719  cached 166396091  write 2458117  output 656433  reasoning 381810  $96.80

Write prices in .crew/rates or ~/.config/crew/rates (dollars per million tokens; a template lives in share/rates). Set budget=<dollars> on a member's line in the Crewfile: crew board shows the percentage spent, crew doctor warns if a budgeted member has no matching rate, and crew watch notifies the owner at 80% and 100%, naming crew mute <name>. crew never stops or kills an agent on its own.

Reference

Commands

Tab completion for fish, zsh, and bash reads crew --help directly and completes commands, flags, member names, keys, message numbers, presets, and kinds.

For everyone

Command What it does
crew help Print the protocol agents follow (share/protocol.md).
crew join <name> [--pane <pane> | --no-pane] Join the crew as <name> from this pane (or without a pane), recording pane, kind, thread, or session, and print the protocol, plan, and unread messages.
crew send <from> <to> <subject> [-m <line>] Post a numbered Markdown message (body on stdin or -m) and wake <to> (a member, all, or owner).
crew unread <name> [--wait [seconds]] Print messages to <name> or all not read yet and advance the cursor; --wait blocks until one arrives.
crew log [count] [--from <m>] [--to <m>] [--grep <pat>] [--since <t>] Print the last messages whole (default 5), filtered when flags are given.
crew show <number>... Print those messages whole by number.
crew status [<name> ["Field: value"...]] Write <name>'s status from stdin or one-line field updates, warning on overlapping Files: claims; or read statuses.
crew report [<name>] Write <name>'s end-of-session report from stdin, or read reports.
crew board [count] | --live [seconds] Show statuses, claim conflicts, unclaimed dirty files, review queue, lock, messages, git, CI, and cost; --live redraws a compact table every 5 seconds.
crew dir Print the crew's directory (.crew/ or ~/.crew/<project>/).
crew lock <name> Take the atomic push lock in .crew/lock/.
crew unlock <name> | --force Release the push lock.
crew sync [<name>] Fetch origin and rebase the member's clone onto origin/main when its working tree has no tracked edits.
crew land <name> -F <file> [--check <cmd>] [--to <member>] -- <path>... Run the check, take the lock, verify claims, commit only the given paths, rebase a clone if origin moved and re-run the check, push, unlock, and send Pushed: to the reviewer.

For the coordinator

Command What it does
crew init [--home] Create .crew/ at the project root (kept out of git) or under ~/.crew/<project>/, seeding a commented README.md plan.
crew up [<preset>] [--dry] Bring the crew of the Crewfile (or preset solo, pair, ring) up or back: tabs, panes, clones, layouts, invites, watch, and live board.
crew down [minutes] [--archive] [--close] Send End:, wait for each member's Done:, report anything left, stop the watch and board, and optionally archive and close exited panes.
crew doctor Check terminal versions, crew on PATH, agents and fixture versions, caveman skills, notifier, gh, lock age, relay, panes, Crewfile, and budget rates.
crew panes List every pane in the terminal, who joined it, its tab, and its kind.
crew cost [name...] Count tokens and dollars spent by each member from local agent logs and the rates file.
crew spawn <name> [--tab <tab> | --beside|--below|--above <m>] [--join] [--kind <k>] [--clone [--cache <dir>]...] <cmd>... Open a named, colored pane for <name> running <cmd> in the shared tree or its own clone.
crew layout [<layout>] [--tab <tab>] Arrange a tab's panes into table, grid, main, <cols>x<rows>, or explicit rows (a,b / c).
crew move <name> --beside|--below|--above <member> Move an open pane right of, under, or over another member's pane while its agent keeps running.
crew invite <name> [seconds] Wait until the agent in <name>'s pane is idle, then type the crew join line with caveman mode.
crew leave <name> [--clone] Forget a member's pane, removing its clone with --clone when nothing unpushed or modified remains in it.
crew mute <name> / crew unmute <name> Wake <name> only for messages addressed to its name, or wake it for all again.
crew focus <name> [--zoom] Bring <name>'s pane to the front (or crew focus - to return to the previous pane).
crew peek <name> [lines] Print the last lines currently drawn in <name>'s pane.
crew poke <name> <line> Type a line into <name>'s pane and press Return.
crew key <name> <key>... Send keystrokes (y, enter, esc, tab, up, ctrl-c, alt-m, …) to <name>'s pane.
crew gate <name>... [--all] [--dry] Read panes every 2 seconds, approve recognised command prompts, and hold commands matching forbid.
crew relay Wake message recipients from outside sandboxed agents.
crew watch <name>... [--all] [--dry] Run crew gate and crew relay together in one pane, with desktop notifications on holds, exits, and budgets.
crew story [<archive>] Write the whole session as one Markdown document: plan, Crewfile, members and spend, stream, commits and reviews, and reports.
crew archive Move the stream, cursors, statuses, and reports into archive/<timestamp>/ and start a fresh stream.
crew version Print the version or commit of crew.

The Crewfile and presets

crew up reads .crew/Crewfile, or copies a built-in preset (solo, pair, ring in share/presets/, overridden by ~/.config/crew/presets/<name>) when the crew has none: 

# Crewfile: tabs and members, in the order crew up places them.
tab main layout=main watch board
tab proof layout=table
member claude   reviewer=claude2 -- claude --model claude-opus-5-5 --effort high
member claude2  reviewer=claude clone cache=.lake -- claude --model claude-opus-5-5
tab runtime layout=grid
member agy      reviewer=codex mute budget=20 -- agy
member codex    reviewer=agy mute budget=60 -- codex

Gate rules (share/forbid and .crew/forbid)

crew gate tests every command prompt against extended regular expressions in .crew/forbid (or share/forbid when the crew has none), stripping ! exception patterns first. By default it holds destructive or shared-tree git commands (git reset, git checkout, git stash, git clean, git add -A, git commit -a, git commit --amend, git push --force), whole-tree formatters, kill, sudo, and recursive deletions (rm -rf), while allowing lock release (rm -rf .crew/lock), format checks (--check), and branch creation (git checkout -b, git switch -c).

Requirements

  • macOS with iTerm2 3.5+ (using osascript) or tmux 3.1+, or Linux with tmux 3.1+.
  • POSIX sh, awk, sed, and git (shipped with macOS and Linux).
  • One or more terminal coding agents on PATH: Claude Code (claude), Codex (codex), Antigravity (agy), or your own kind in ~/.config/crew/kinds.
  • Optional: gh (for CI status on crew board), sqlite3 (for Antigravity token counts in crew cost), and notify-send on Linux (for desktop notifications to owner).
